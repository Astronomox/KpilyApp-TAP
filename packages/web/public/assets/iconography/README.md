# KPILY Iconography

This folder contains the supplied KPILY SVG iconography assets plus the responsive navigation icon added for checkpoint1.

## Usage

Reference an asset from the web package with an absolute public path:

```tsx
<img src="/assets/iconography/hamburger-menu.svg" alt="" aria-hidden="true" />
```

The interactive hamburger control uses CSS lines so it can animate into a close icon while this SVG remains available as a static asset for documentation, menus, and other surfaces.
